# ClearHot: handoff package for an LLM

## Start here

Give the LLM **`PROMPT_FOR_LLM.md`** and the whole ZIP. The task is to inspect the existing code, research and improve suppression of parallel/static lines, digital picture enhancement and the feasibility of CNN training, with honest evaluation. The code and the working standalone preview are included; the challenge organizer's raw video is **not** included.

## Package contents

- `PROMPT_FOR_LLM.md` — detailed problem, constraints, research and implementation requests.
- `clearhot-lab/` — self-contained Vite/React/TypeScript source for the **current isolated workbench**, with package lockfile. This is the primary code to inspect and improve.
- `preview/ClearHot_Lab.html` — built standalone single-file browser version of that workbench. Open it locally in a modern browser; the user chooses the input file on their machine.
- `ClearHot_Test_and_CNN_Exploration_Plan.md` — usage notes, current limitations, data considerations and evaluation/research plan.
- `reference/ThermalClearHotView_original_archive.tsx` — exact component extracted from the original `ideasstudiosim2.zip`; kept as a historical reference, not the main runnable app. May contain unsupported claims and weaker file validation.
- `reference/ThermalClearHotView_ideastudio2_reviewed.tsx` — the component from the reviewed Idea Studio 2 before creation of this isolated lab, for comparison.
- `clearhot-lab/tests/synthetic-browser-test.cjs` — optional portable browser smoke test using generated inputs only; see below.

## Run the current source

Requires a compatible Node.js version (Vite 7 requires Node 20.19+ or 22.12+). In `clearhot-lab/`:

```sh
npm ci
npm run build
npx tsc --noEmit
npm run dev
```

Open the local URL Vite prints. Production output `dist/index.html` is a standalone HTML generated by `vite-plugin-singlefile`. The app reads chosen raw files in the browser; the user chooses their own file. `npm ci` installs packages and needs network access; the included HTML preview does not require a package install.

The development server is configured with `host: 0.0.0.0` and `allowedHosts: true` for a cloud-preview environment. **For a personal machine or sensitive network, bind to loopback and restrict allowed hosts**, e.g. `npm run dev -- --host 127.0.0.1`. Do not expose the dev server publicly with sensitive files or assumptions.

### Optional browser test

The test uses Playwright, which is not a project dependency; install it and a compatible Chromium only if needed and allowed (browser downloads can be large):

```sh
npm install --no-save playwright
npx playwright install chromium
npm run build
node tests/synthetic-browser-test.cjs
```

The test constructs two 640 × 512 striped frames, checks actual uploaded-data rendering, the line sliders, frame selection, PNG export and error handling. Results concern **synthetic inputs only**. It requires graphical/browser dependencies appropriate to the OS. Its availability and pass status depend on the local environment.

## Evidence boundary

The owner reports that the preceding ClearHot preview made the organizer's data appear visually better; that observation is useful and deserves investigation. Neither this ZIP's author nor the included tests inspected the actual challenge file or independently verified visual quality, challenge compliance, real-time speed or FPGA feasibility. The current app has **no trained CNN**, training workflow, inference engine, complete video export or real FPGA implementation. Do not present placeholders or synthetic metrics as measured outcomes.

**Privacy and size:** The raw `.bin` stays with the user. Do not download, upload or copy large datasets or model weights without explicit permission and available storage. Ask for a small, permitted, representative excerpt if needed. Check the challenge's data use and licensing rules before training or sharing.
