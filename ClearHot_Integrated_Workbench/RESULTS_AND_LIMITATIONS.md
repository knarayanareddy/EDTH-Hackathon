# Integrated workbench: actual results and limitations

## Tested in this build

Environment and exact command output: `QA/environment.txt`, `QA/node-tests.log`, `QA/python-without-torch.log`, `QA/browser-tests.log`. Linux x86-64; Node 20.20.2; npm 10.8.2; Python 3.13.18; NumPy 2.3.5; **PyTorch not installed**. No Mac/MPS, private recording, real labels or external reference were available.

- Clean Node install, build and TypeScript check passed. `npm test`: **18 pass, 0 fail, 1 skip** (19 total). Skip = actual Python-produced saved-model/cache fixture, not treated as pass. Original Argos 2 engine matches the original archive; synthetic default output parity including reset/seek passed. Node >60-frame test checks the classical runner, not neural inference.
- Delivered HTML under `file://`: 5 Playwright browser scripts passed on generated fixtures; original player, 12-method blind review, 640×512 two-frame file, file hashing, seek, five-frame playback, preset storage across reload, tuned Argos 2 vs unchanged default, actual difference when changing detail, method-specific UI, frozen 13th candidate and exported setting, and two experimental-method playback paths were checked. Zero page errors/HTTP requests were observed in these tests only. Sliders and conditional stage effects have **not** each been exhaustively tested in every method. Experimental variants are not proven superior.
- A 65-frame synthetic **fabricated cache** played to frame 64 and showed the matching cache entry, using a big-endian shifted source and little-endian cache. Wrong-source hash was rejected and bypass hid the output. This tests viewer synchronization, **not neural inference**. The manifest was marked UNAPPROVED; its fake hashes and bytes are not a real checkpoint.
- Six independent Python unit tests passed using NumPy and stubs where needed: real-mask import/hash/shape/attestation and no-overwrite, missing-evidence gates fail, registry duplicate/approval/status/tamper checks. The registry tests use fake model bytes and stub `report_csv`; they do **not** test PyTorch or real weights.
- Earlier source author's results are separately preserved as reference, not claimed as our own results.

## Known limitations / follow-up

1. No independently run PyTorch training, saved-weight inference, full learning-loop restart, actual-cache browser playback or MPS inference. Python source including new mask import and strengthened registry requires testing in the supported environment; no large dependencies downloaded here. Neither Mac installation nor performance is verified. Default synthetic model may fail preservation gates; demo approvals use TEST-ONLY relaxed gates.
2. Real import requires externally created trusted aligned reference frames and pixel masks. No mask editor, annotation QA or calibrated reference is supplied. Ring/feature metrics aggregate pixels and can hide individual losses; validate them scene by scene. Stripe-free status is attested, not independently verified. Distinct hashes do not prove independent scenes. Missing evidence fails closed.
3. Original Argos 2 guided detail is fused with tone: stage-4 bypass is not a genuine isolated detail ablation. The UI makes this explicit. Line/bad-pixel stage is coupled. Some tuning controls do nothing if their parent stage is disabled or for some inputs. Some earlier UI features and experimental browser CNNs are deliberately not restored.
4. Only 14-bit-in-uint16 input; no per-frame headers, row padding or packed formats. Default geometry, bit alignment, 5500–7500 display window, and frame rate are unconfirmed. Original methods have native tone and distinct temporal behavior. Claude B can use future frames. Reset on seek means a still can differ from a sequential frame after warm-up. No deliberate video frame skipping, but real-time performance is unproven.
5. Experimental Argon variants received code adaptation and synthetic execution/reset tests, not comprehensive hard-negative or real-data safety validation; their prior source claims are not endorsed. They are not the original Argos 2 algorithm.
6. The training implementation creates a fresh network rather than resuming prior weights. The final-test command logs calls but does not prevent repeated use. A saved cache is static: rollback changes future inference, not existing cache contents. A manifest's status is self-reported local metadata; consistency checks and hashes are not independent proof of approval or model output provenance.
7. Presets only include method parameters, not decoder/window or source; sessions record the decoder and the selected tuned candidate separately. Browser storage is not guaranteed to persist. Export a JSON backup. Session exports, recordings, data, frame caches and model weights may be sensitive. Browser tests are not a comprehensive privacy/security audit.
8. The model registry uses atomic replacement for individual files/pointer but does not provide a transactional multi-file database or concurrency guarantees. Active-state consistency checks fail closed; a crash may require manual recovery. Do not use concurrent writers.
9. The source archives and reference material are included for provenance; do not run unreviewed old server/database interfaces for sensitive material. Only `ClearHot_Local.html` is the integrated viewer.
