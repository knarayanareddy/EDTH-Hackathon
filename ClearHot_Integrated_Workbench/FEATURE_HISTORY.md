# ClearHot progression and feature inventory

The user's recording was previously tried by the user in six original instances, with a visual preference for Argos 2; it was not available here. No version is established to improve that recording.

| Stage | What it contributed | What was lost / caution | Here |
|---|---|---|---|
| Original Argos 1–3 | Actual classical engines; instance controls for correction, detail, AGC and method-specific stages | Some claims/metrics were unsupported; state could leak across seeks | Original engine and defaults preserved; many actual controls restored as sliders/numbers; resets at seek |
| Original Claude A–C | Actual classical methods; rich parameter exploration, experimental TF.js CNN work | Claude B can look ahead; CNN not proven; independent display algorithms | A/B/C classical engines and relevant actual controls; CNN disabled in those original engines |
| Combined six-method preview | Kept both original interactive workspaces accessible | Two separate apps; shared source could desynchronize | One shared decoder/player, not embedded original UIs; not every old feature or original CNN UI restored |
| Later Claude experimental lab | ROI, line correction, detail, CLAHE and synthetic evaluation ideas | Did not preserve original six; unsupported 16-bit behavior | Baseline 12 blind methods, ROI review and lab configurations retained; this is not the full earlier lab UI |
| Later Argon workbench | Classical candidates and stage ablation concepts | Seeded votes, misleading claims, rewritten originals, player and persistence defects | Not imported wholesale; newer isolated variants selected as experiments, not certified or exact originals |
| Local comparison/player | Shared 14-bit decoder, exact original methods, blind ratings, ROI/session exports, complete sequential playback | Frozen defaults removed tuning | Preserved and extended with separate tuning, presets and optional 13th frozen blind candidate |
| Latest Claude submission | PyTorch trainer, fail-closed missing evidence, local checkpoint workflow and hash-checked cache | Missing binary artifacts; no real masks; demo relaxed gates; Python/Mac unverified | Source included; reference archives restored; mask import + approval consistency checks added, still not end-to-end verified here |
| Latest Argon submission | Guided/cored and causal experimental paths; real JS synthetic training | Shipped HTML broken, unsafe cache and approval/gates, duplicate active ID | Only two isolated classical variants adapted, no Argon CNN/registry/cache imported; synthetic smoke tests only |

Source is in `src/`, local training in `training/`, original and later ZIPs retained under `provenance/reference_submissions/` only for inspection, not as active components. Earlier independent reviews are in `provenance/reviews/`; they concern the original submissions, not this integrated build. Exact default Argos engine bytes and default parity tested against the original archive. The generated HTML is self-contained.

Not every previous button, interface feature, data view, algorithm or visualization is here. We have not merged the old browser-CNN training tools, Argon's unsafe registry or the old server/database interfaces. Tuned original method parameters are not applied to the PyTorch evaluator, which compares frozen default Argos 2 stage-1; a tuned preset is a **visual/blinded still** candidate and not an alternative neural validation baseline.
